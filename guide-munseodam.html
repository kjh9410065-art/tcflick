MUNSEODAM GUIDE

내 문서를 기준으로
답변을 확인하세요.

문서담(MunseoDam)은 자주 사용하는 문서 양식을 선택하고 필요한 내용을 입력해 문서를 작성한 뒤 미리 보고 인쇄할 수 있는 문서 작성 서비스입니다.

이런 경우에 적합합니다

  • 필요한 문서 양식을 빠르게 작성하고 싶을 때
  • 사직서·위임장·차용증 등 자주 사용하는 문서를 직접 작성하고 싶을 때
  • 문서 종류를 선택하고 필요한 입력값만 채워 문서 작성을 간소화하고 싶을 때

이용 흐름

  1. 작성하려는 문서 양식을 선택합니다.
  2. 필요한 내용을 입력합니다.
  3. 미리보기에서 작성 결과를 확인합니다.
  4. 필요하면 작성 내용을 수정한 뒤 인쇄합니다.
  5. 개인정보가 포함된 문서는 인쇄·보관 전에 입력 내용을 다시 확인합니다.

사용할 때 주의할 점

문서 양식은 작성 편의를 위한 기본 서식입니다. 계약·법률·업무 문서처럼 중요한 문서는 실제 제출처의 요구사항과 최신 기준을 확인한 뒤 사용하세요.

외부 서비스 안내
문서담은 TCFLiCK 메인 사이트와 별도로 운영되는 서비스입니다. 실제 이용 화면과 현재 제공 기능은 문서담 서비스에서 확인하세요.
